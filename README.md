# 個人化運動賽程規劃工具

**打造你的專屬賽程。** 這是一個網頁小工具，把你追的足球、NBA、MLB、NFL、網球、F1 賽程放在同一頁，並且只顯示你方便看的時段（台灣時間）。

👉 **立即使用：https://xuancissus.github.io/match-schedule/**

手機、平板、電腦的瀏覽器都能開。免費、免註冊、沒有廣告。

---

## 為什麼做這個

- 歐洲足球和 F1 常在台灣時間凌晨開賽，官方賽程不會告訴你「哪幾場不用熬夜就能看」。
- 追不同運動要開好幾個 App；一般比分 App 又塞滿所有比賽，自己關心的那幾隊反而要慢慢找。
- 訂閱球隊行事曆看得到賽程，但沒辦法自動排除深夜場次。

## 功能

- **六種運動在同一頁**
  - 足球：英超、西甲、德甲、義甲、法甲、荷甲、葡超、蘇超、美職、沙烏地聯賽，加上歐冠、歐霸、歐協聯和國內盃賽
  - 足球國家隊：六大洲約 215 支男足國家隊（世界盃與資格賽、洲際盃賽、歐國聯、國際友誼賽）
  - 籃球：NBA（季前賽、例行賽、季後賽）
  - 棒球：MLB（例行賽、季後賽；不含春訓）
  - 美式足球：NFL（季前賽、例行賽、季後賽）
  - 網球：ATP／WTA 單打
  - F1：練習賽、排位賽、衝刺賽、正賽
- **只追你在乎的**
  - 足球、NBA、MLB、NFL：追蹤球隊
  - 網球：追蹤選手，從世界排名前 150 名挑選
  - 可以用中文或英文即時搜尋球隊和選手（中文名稱靠內建對照表，少數較冷門的選手只能用英文找）
  - F1：預設關閉，開啟後可以分場次勾選
- **開賽時間篩選**：自訂「從幾點到幾點開賽才顯示」，30 分鐘一格，預設 06:00–01:30（台灣時間）。
- **一天一個頁籤**：每天標出場次數。預設顯示本週，也可以自訂日期區間。
- **結果一目了然**
  - 勝方標「勝」，和局兩邊都標「和」
  - 網球顯示每盤比分和搶七
  - 進行中、時間未定、對手退賽等狀態用文字標示
- **積分榜**：足球各聯賽（國家隊沒有積分榜）、NBA 東西區、MLB 美聯／國聯、NFL AFC／NFC、ATP／WTA 前 20、F1 車手與車隊。你追蹤的隊伍和選手會被標亮。
- **省流量**：開過的資料會先存在瀏覽器裡，重複開啟時畫面馬上出來，只有比賽進行中、剛結束或資料過期才重新下載。按「↻ 更新」一律抓最新資料。
- **賽事數據**：已結束的比賽可以一鍵跳到 Google 的賽事卡片。
- **深淺色模式**：自動跟隨系統設定。手機上的按鈕和字級也調整過，方便點選和閱讀。

## 使用方式

1. 打開上面的網址，按「**篩選器**」，選擇想追蹤的球隊、選手，以及開賽時段。
2. 按「**完成**」就會套用，之後打開都會記得你的設定。
3. **手機建議加入主畫面**：在 Safari 按「分享」→「加入主畫面」，就能像 App 一樣從桌面開啟。
4. **換裝置**：在篩選器的「設定」區匯出設定檔，到另一台裝置匯入即可。

## 隱私

- 不需要帳號，不蒐集任何資料。
- 你的追蹤清單和設定**只存在你自己的瀏覽器裡**，不會上傳到任何地方。清除瀏覽器的網站資料後，設定就會消失。

## 資料來源

| 用途 | 來源 |
|---|---|
| 足球、NBA、MLB、NFL、網球賽程與排名、F1 排名 | ESPN 網站公開的資料介面（非官方 API） |
| F1 賽程 | [Jolpica F1](https://github.com/jolpica/jolpica-f1)（社群維護的免費 API） |
| 數字字體 | [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)（Google Fonts） |

資料是你的瀏覽器直接向上述來源抓取，不經過任何中間伺服器。

## 限制

- 時間固定為台灣時間（UTC+8），目前不能切換時區。
- 資料來源是公開但非官方的介面，偶爾可能抓不到或延遲。重要比賽請以官方公告為準。
- 只涵蓋本季的賽程。
- 隊名和選手名是英文。

## 技術

- 主程式是單一 HTML 檔，沒有用任何框架，也不需要建置。下載 `index.html` 後直接用瀏覽器打開也能用；`zh-*.js` 是中文搜尋用的名稱對照表，放在同一個資料夾才能用中文搜尋。
- 使用 [Claude Code](https://claude.com/claude-code) 以 AI 協作方式開發。
